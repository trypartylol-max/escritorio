# Escritorio

Lanzador personal: una sola página que une las apps (SHAAH, Cocina, Caja, Libro Mayor, WiFi Doctor, formularios…) con un widget en vivo de Plata26.

- **App:** https://trypartylol-max.github.io/escritorio/
- Cada app es un proyecto independiente con su propio repo; Escritorio solo las enlaza.
- Datos: API de Apps Script de Plata26 (clave del dispositivo o sesión de Google de SHAAH). Ningún dato personal vive en este repo.
